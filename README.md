Overview

This repository contains a security audit and remediation for a Flask application originally provided in inputs.py. The important files created or modified by the audit are:

- input_backup.py: Exact backup copy of the original, vulnerable source file.
- input.py: Hardened, secure implementation with fixes and validation.
- report.json: Structured JSON report listing vulnerabilities and fixes.
- tests/: Pytest unit tests that demonstrate vulnerable behavior in input_backup.py and verify fixes in input.py.
- requirements.txt: Python dependencies.
- run_test.sh / run_test.bat: Platform-specific scripts to run tests.
- auto_test.py: Automatic test runner that detects platform, runs tests for backup and fixed files, and writes logs to logs/test_run.log
- Dockerfile: Containerized environment for running tests.
- setup.sh: Helper script to create virtual environment and install dependencies.
- logs/test_run.log: Test execution log generated by auto_test.py (created after running auto_test).

Setup

Linux / macOS:
1. ./setup.sh
2. source .venv/bin/activate

Windows (PowerShell):
1. python -m venv .venv
2. .\.venv\Scripts\Activate.ps1
3. pip install -r requirements.txt

Running tests

Linux / macOS:
- Run all tests: ./run_test.sh
- Run only backup tests: ./run_test.sh backup
- Run only fixed tests: ./run_test.sh fixed

Windows:
- Run all tests: run_test.bat
- Run only backup tests: run_test.bat backup
- Run only fixed tests: run_test.bat fixed

Automatic testing

Run auto_test.py to detect the environment and run both backup and fixed test sets in sequence. Logs are appended to logs/test_run.log and include timestamps and PASS/FAIL status lines for each run.

Example:
python auto_test.py

Inspecting logs

Open logs/test_run.log to see the detailed output for each run. Each log line has an ISO8601 UTC timestamp. The end of the file contains a final status line: TEST PASSED or TEST FAILED

Notes

- Secrets are expected to be provided via environment variables: PAYMENT_TOKEN, MAIL_SERVER_KEY, INTERNAL_AUTH, API_KEY
- The fixed code forbids reading arbitrary files and will only read YAML files from the configured SAFE_CONFIG_DIR (defaults to ./configs)
